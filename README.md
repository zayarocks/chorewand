# Magic Chore Wand
An ESP32-based handheld device that uses NFC tags to record the completion of household tasks. The wand provides audiovisual feedback through a NeoPixel LED ring and an MP3 playback module while synchronizing task completion with a web-based chore tracker.

## Parts List
- [ ] ESP32
- [ ] WS2812B NeoPixel ring
- [ ] PN532 NFC reader
- [ ] NTAG215 NFC stickers
- [ ] DFPlayer Mini
- [ ] 8GB microSD preloaded with MP3
- [ ] 8Ω 1W miniature speaker
- [ ] Momentary push button (purchased or homemade)
- [ ] Miscellaneous electronic components (wires, resistors, capacitors)
- [ ] 3D-printed enclosure
